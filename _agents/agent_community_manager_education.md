## 1. Objectif de ce document

Ce document contient le system prompt complet à copier dans un nouveau Projet Claude pour créer l'agent Community Manager Éducation. Cet agent produit à la fois des publications prêtes à diffuser et une stratégie éditoriale structurée, adaptées aux trois cibles prioritaires : parents d'élèves CM1-CM2, enseignants du primaire, et communautés éducatives en ligne.

## 3. Structure du Projet Claude recommandée

### 3.1 Fichiers à joindre immédiatement au projet

| `roadmap_lemondedescurieux_mars2026.md` | Vue complète du site, gamification, matières — base de tout contenu |

### 3.2 Fichiers à ajouter selon le besoin

Les fichiers HTML des sections ne sont pas nécessaires pour cet agent — il travaille sur la communication externe, pas sur le code. Si Guillaume souhaite communiquer sur une fonctionnalité spécifique (export PDF, PWA, badges), lui décrire la fonctionnalité directement dans le prompt suffit.

## 4. Workflow standard — Comment utiliser l'agent

### 4.1 Exemples de demandes types

| Situation | Exemple de prompt | Ce que l'agent fait |
|---|---|---|
| Post rapide | "Rédige un post Facebook pour présenter la section Maths aux parents" | Post 200 mots, ton parent, lien + call-to-action |
| Lancement | "Prépare une série de 3 posts LinkedIn pour annoncer le site aux enseignants" | Série cohérente avec progression narrative |
| Calendrier | "Génère le calendrier éditorial d'avril 2026" | Planning semaine par semaine, sujets + plateformes |
| Communauté | "Rédige un message d'introduction pour le groupe Viaéduc CM2" | Message entre pairs, humble et direct |
| Argument | "Comment présenter la conformité RGPD comme avantage aux enseignants ?" | Formulations adaptées selon la plateforme |

## 5. Notes importantes

Le positionnement "projet indépendant, solo developer, sans publicité, 100% RGPD" est un avantage différenciant fort dans un marché où la plupart des sites éducatifs gratuits sont financés par la publicité ou collectent des données. Ce positionnement doit être assumé et mis en avant, particulièrement auprès des enseignants sensibilisés au numérique responsable.

Guillaume étant en reconversion professionnelle, l'histoire du projet (certification TAI, projet pédagogique personnel) est un vecteur de sympathie authentique auprès des communautés en ligne — à utiliser avec mesure mais sans fausse modestie.
